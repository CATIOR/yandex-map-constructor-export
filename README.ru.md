# Конструктор карт Яндекса — Экспорт в высоком разрешении

> [English version (README.md)](./README.md)

Юзерскрипт для экспорта карт и схем из Конструктора карт Яндекса (`yandex.*/map-constructor`) в PNG высокого разрешения без штатных ограничений по размеру и масштабу.

## Возможности

- **Прямая загрузка тайлов** для любого зума (поддержка Схемы, Спутника и Гибрида).
- **Ускоренный режим** при большом количестве тайлов (> 2000) с выбором между полным зумом и `z-1` при `scale=4` (в 4 раза меньше запросов).
- **Векторная отрисовка** линий и полигонов через `Path2D` (с резервным рендером других SVG-элементов).
- **Масштабирование меток, линий и подписей** (`1x`–`4x` или `Авто` для крупных карт).
- **Авто-подгонка размеров** (`🎯 Авто-размер под все объекты`) и авто-центровка схемы при экспорте.
- **Выбор фона:** карта с тайлами, светлый фон или прозрачный PNG.
- **Защита от переполнения памяти 2D Canvas** с автоматическим снижением множителя в рамках лимитов браузера (`32000 px` по стороне, `~260 MP` по площади).

## Установка

1. Установите менеджер юзерскриптов:
   - [Tampermonkey](https://www.tampermonkey.net/)
   - [Violentmonkey](https://violentmonkey.github.io/)
2. Установите файл [`yandex-map-constructor-export.user.js`](./yandex-map-constructor-export.user.js) (нажмите **Raw** на GitHub или установите через GreasyFork).
3. Откройте Конструктор карт Яндекса — внизу слева появится перетаскиваемая панель управления.

## Использование

1. Если вместо зума отображается `—`, слегка сдвиньте или прокрутите карту, чтобы скрипт подхватил активный экземпляр карты.
2. Нажмите **«🎯 Авто-размер под все объекты»** или задайте ширину и высоту вручную.
3. Выберите множитель (`1x`, `2x`, `3.125x` для 300 DPI), режим фона и масштаб меток.
4. Нажмите **«💾 Скачать карту в PNG»**.

## Приватность и ограничения

- Скрипт работает полностью локально в браузере и не отправляет данные на сторонние серверы.
- Предельный размер итогового файла ограничен лимитами памяти 2D Canvas вашего браузера.
